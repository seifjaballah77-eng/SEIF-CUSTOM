# SEIF CUSTOM — المواصفات وحالة التنفيذ

> المبدأ: **المستخدم هو صاحب القرار.** لا تغيير تلقائي ولا نقل أو حذف أو إخفاء إجباري. كل شيء اختياري ويمكن التراجع عنه.

## الكمبيوتر والمتصفح
- تبويب جديد صغير الخيارات، شفاف وزجاجي، ساعة وتاريخ وبحث ومواقع مختصرة قابلة للإضافة والحذف.
- خلفيات محلية ثابتة ومتحركة GIF/WebP وفيديو MP4/WebM/OGG، مع كتم الفيديو وتكراره وإيقاف الحركة عند إخفاء الصفحة.
- منزلق مستقل لشفافية الخلفية وشفافية اللوحات، ومظهر نهاري/ليلي يدوي فقط.
- حفظ محلي واستيراد/تصدير إعدادات. الإضافة تغيّر New Tab فقط ولا تتحكم في صفحات المتصفح المحمية أو Windows.
- زر تنزيل دائم يفتح مركز التنزيل؛ يشمل روابط APK وZIP وسجل البناء.
- تصميم الكمبيوتر يجب أن يبقى خفيفاً: عناصر صغيرة، قليلة، وشفافة.

## محاكي الهاتف على الكمبيوتر
- صفحة `extension/simulator.html` تعرض هاتفاً افتراضياً تفاعلياً داخل الكمبيوتر مع صفحات الرئيسية والتطبيقات والودجات.
- تخصيص لون الواجهة والخلفية والشفافية والأشكال وحجم الجهاز، ورفع صورة أو فيديو كخلفية معاينة.
- حفظ التفضيلات وملف الخلفية محلياً في المتصفح.
- التطبيقات روابط خارجية قابلة للتعديل؛ النقر على الأيقونة يفتح الموقع الرسمي أو صفحة التنزيل في تبويب جديد.
- هذا محاكي تصميم وليس Android Emulator؛ لا يشغّل نظام Android أو APK.

## Android
- مشغّل Launcher بديل، يعرض التطبيقات ويتيح إخفاءها داخل واجهته فقط وإعادتها لاحقاً.
- مركز التطبيقات المطوّر: بحث بالاسم أو اسم الحزمة، تبويبات الكل/المفضلة/المخفية، مفضلة لكل تطبيق، تشغيل التطبيق، وإخفاء/استعادة من مشغّلنا.
- لا نعد بإخفاء التطبيقات من إعدادات Android أو المشغلات الأخرى أو إحصاءات Digital Wellbeing/وقت الشاشة. لا يمكن لتطبيق عادي محو أو تزوير سجلات استخدام النظام. Private Space ميزة يديرها Android/الشركة المصنّعة وليست تجاوزاً نتحكم به.
- خلفيات محلية: GIF، صور ثابتة، وفيديوهات حية بحسب دعم ترميز الهاتف.
- منزلق وضوح/شفافية؛ شفافية GIF والصور مطبقة في محرك الخلفية الأولي. الفيديو يستخدم MediaPlayer مباشرة وقد لا يدعم الشفافية لكل بكسل.
- معاينة النظام الرسمية قبل تطبيق الخلفية. لا يغير التطبيق خلفية الهاتف حتى يوافق المستخدم من شاشة المعاينة.
- إيقاف الحركة عند عدم ظهور الخلفية. لا تفعيل لتوفير الطاقة ولا تبديل تلقائي للنهار/الليل.

## استوديو التصميم
- ألوان مستقلة لكل عنصر، مكتبة ألوان واسعة، تدرجات، شفافية، حدود، ظلال وإضاءة.
- أشكال: مربع ناعم، دائري، كبسولة، عضوي، سداسي، حواف حادة ومخصص.
- حجم ومسافات ومحاذاة ومعاينة فورية، مع الحفاظ على وضوح النص وحجم اللمس.
- قوالب قابلة للتعديل، تصميم من الصفر، حفظ/نسخ/إعادة تسمية/استيراد/تصدير/مشاركة، تراجع واستعادة.

## التطبيقات والأيقونات
- مكتبة أيقونات مصنفة حسب نوع التطبيق والبحث، استيراد أيقونة، تغيير الاسم داخل المشغّل، أشكال مختلفة وEmoji اختياري.
- المفضلة والبحث والإخفاء داخل مشغّلنا مطبقة كبداية. المجلدات والإيماءات وتخصيص أيقونات كل تطبيق ما زالت ضمن العمل.
- كل تطبيق مخفي يمكن استعادته. الإخفاء داخل المشغّل فقط ولا يخفيه من إعدادات Android أو إحصاءات الاستخدام.

## الخلفيات
- مكتبة مستهدفة 120 خلفية منتقاة ومرخصة: طبيعة، شلالات، بحار، جبال، غابات، سماء، فضاء، سيارات، مدن، عمارة، 3D، تجريد، Neon، تدرجات، أسود/ذهبي، مستقبل، زهور وفن معاصر.
- لا صور دينية/جنائزية/أصنام/كنائس/لوحات كلاسيكية وفق تفضيل صاحب المشروع. لا نسخ من Pinterest بلا ترخيص.
- تصنيف وبحث ومفضلة ومعاينة وتنزيل وتطبيق وتدوير يدوي/اختياري.

## Widgets
ساعة، طقس، تقويم، بطارية، تاريخ واختصارات؛ أحجام وألوان وأشكال وشفافية. يلزم تنفيذ Android AppWidget حقيقي.

## لوحة المفاتيح
لوحة IME اختيارية؛ تخصيص الخلفية والأزرار والحروف والرموز والمسافة والحذف والإدخال. لا تصغير للمفاتيح أو إضعاف وضوح الحروف، ولا تسجيل أو إرسال النصوص.

## الخزنة والخصوصية
- المطلوب خزنة صور وملفات مشفرة فعلياً، نقل/استعادة اختياريان، كلمة مرور، مفتاح استرداد، وبصمة/وجه حسب مستوى أمان الجهاز.
- بعد 10 محاولات فاشلة: طلب تصوير أمامي فقط إن سمحت الأذونات والنظام وبشكل ظاهر. بعد 17 محاولة: قفل مؤقت دقيقة. لا تصوير خفي أو رفع للخادم.
- يجب ألا يؤدي فقدان مفاتيح التشفير إلى وعد باستعادة الملفات دون مفتاح.
- يوجد حالياً ملف AES-256-GCM Android Keystore كقاعدة تشفير فقط، وليس خزنة مكتملة أو واجهة مستخدم.

## التنزيل والتوزيع
- صفحة تنزيل مدمجة في نسخة الكمبيوتر، فيها رابط APK Android وملف ZIP للمصدر وروابط بناء الاختبار.
- `.github/workflows/android-build.yml` يبني APK debug ويرفعه كـ Actions artifact عند تغييرات Android.
- `.github/workflows/android-release.yml` يبني APK وينشر APK وSource ZIP كأصول GitHub Release عند التشغيل اليدوي أو دفع tag يبدأ بـ v.
- لا يوصف APK بأنه جاهز قبل نجاح البناء. أول رابط latest/download لن يعمل قبل نشر أول Release.

## الأتمتة والطاقة
- توفير الطاقة ليس دائماً. الوضع النهاري/الليلي لا يتغير تلقائياً.
- يمكن للتطبيق اقتراح إجراء؛ التنفيذ بعد موافقة صريحة. كل إعداد اختياري وقابل للتعطيل.

## قيود المنصة
- تغيير المشغّل الخاص بنا ممكن، لكن تعديل SystemUI الأصلي أو شريط الإشعارات أو شاشة القفل أو Settings مقيد.
- الوجه الآمن والمصادقة الحيوية يعتمدان على إمكانات الجهاز.
- إضافة المتصفح تتحكم في New Tab فقط.
- أي ميزة لا تجتاز اختبار الجهاز لا تُعلن كميزة مكتملة.

## حالة التنفيذ
### موجود في المستودع
- محاكي هاتف تفاعلي على الكمبيوتر مع معاينة الصفحات وتخصيص المظهر وإدارة روابط التطبيقات.
- إضافة متصفح: ساعة، تاريخ، بحث، اختصارات، ثيم يدوي، شفافية لوحات وخلفية، صورة/GIF/WebP وفيديو محلي، تخزين محلي واستيراد/تصدير إعدادات.
- مركز تنزيل مدمج مع رابط APK للإصدار الأخير ورابط ZIP للمصدر وسجل بناء Android.
- Android starter: Activity قابلة للاختيار كمشغّل، مركز تطبيقات مطوّر ببحث ومفضلة وتبويبات ظاهرة/مخفية، إخفاء/استعادة داخل المشغّل، اختيار ملف محلي، خدمة خلفية حية للفيديو وGIF والصور الثابتة، لوحة مفاتيح أولية، ودجت ساعة/تاريخ، وأساس AES-GCM في Android Keystore.

### لم يكتمل بعد
- التحقق من نجاح Android compile بعد آخر تحديث؛ يجب فحص GitHub Actions.
- لا يوجد APK نهائي منشور حتى تنجح عملية Android Release.
- واجهة الخزنة الكاملة والاسترداد والبيومتري وسجل المحاولات. لوحة المفاتيح الحالية أولية وتحتاج تخصيص ألوان/أشكال/أحجام متقدم.
- Android widgets المتقدمة، استوديو الثيمات والأيقونات الكامل، مكتبة 120 خلفية، ملفات التطبيقات والمجلدات والإيماءات المتقدمة، ومرافق Windows.
